Split Array Largest Sum

Difficulty: HardAccuracy: 58.9%Submissions: 63K+Points: 8
Given an array arr[] and an integer k, divide the array into k contiguous subarrays such that the maximum sum among these subarrays is minimized. Find this minimum possible maximum sum.

Examples:

Input: arr[] = [1, 2, 3, 4], k = 3
Output: 4
Explanation: Optimal Split is [1, 2], [3], [4]. Maximum sum of all subarrays is 4, which is minimum possible for 3 splits.
Input: arr[] = [1, 1, 2], k = 2
Output: 2
Explanation: Splitting the array as [1, 1] and [2] is optimal. This results in a maximum sum subarray of 2.
Constraints:
1 ≤ k ≤ arr.size() ≤ 105
1 ≤ arr[i] ≤ 104

class Solution {
    public int splitArray(int[] arr, int k) {
        
        if(arr.length<k){
            return -1;
        }
        
        int low = Arrays.stream(arr).max().getAsInt();
        int high = Arrays.stream(arr).sum();
        
        while(low<=high){
            int mid = low+(high-low)/2;
            
            int sum = splitArraySum(arr,mid);
            
            if(sum>k){
                low = mid + 1;
            }else {
                high = mid - 1;
            }
        }
        
        return low;
    }
    
    private int splitArraySum(int[]arr, int total){
        
        int sumVal = 1;
        int totalSum = 0;
        
        for(int i=0;i<arr.length;i++){
            if(arr[i]+totalSum<=total){
                totalSum += arr[i];
            }else {
                sumVal++;
                totalSum = arr[i];
            }
        }
        
        return sumVal;
    }
};
